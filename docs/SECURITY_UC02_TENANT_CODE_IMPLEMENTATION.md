# Security UC02 — Internal Tenant Code Implementation Note

**Status:** IMPLEMENTED WORK PACKAGE SEC-UC02-01  
**Date:** 2026-08-21  
**Branch:** `dev`  
**Governing design:** `SECURITY_IMPLEMENTATION_DESIGN_v2.1.md` section 3

## Scope

This note records the existing-compatible internal Tenant Code convention selected for UC02 Project creation. It does not add business meaning to Tenant Code and does not change Audit Core Project fields.

The external Security create request is now:

```json
{
  "tenantName": "Hyundai West Audit Project"
}
```

The caller does not control `tenantCode`.

## Generated internal convention

Security generates:

```text
tenant-<32 lowercase UUID hex characters>
```

Example shape only:

```text
tenant-0123456789abcdef0123456789abcdef
```

Properties:

- generated by Security immediately before Tenant creation;
- 39 characters, within the existing `tenant_code` varchar(80) contract;
- lowercase and hyphenated, compatible with existing opaque Tenant Code usage such as the approved `test-tenant` internal test Tenant;
- backed by UUID randomness and the existing database uniqueness constraint;
- returned by Security for internal/cross-module correlation but not collected as a UC02 Web field;
- not used as an authorization key;
- not Project/Dealer/Outlet business data.

A database uniqueness conflict remains fail-closed as HTTP 409. Retry/idempotency for the logical Project/Tenant create operation is a separate required UC02 Security work package and must be completed before Audit Core Project creation is considered retry-safe.

## Targeted acceptance

- create body no longer defines caller `tenantCode`;
- generated code matches the documented internal convention;
- a stale caller-supplied `tenantCode` cannot control the persisted value;
- Tenant remains `CONFIGURING` after creation;
- existing SuperAdmin human authorization boundary remains unchanged.

## Explicitly not completed by this package

- create idempotency / retry receipt;
- Tenant hard delete;
- exact Tenant deletion dependency graph;
- any Audit Core or DI change.
